# Seleção dos materiais

Examinei 20 arquivos Python da pasta fornecida e selecionei nove DAGs com responsabilidades complementares. Mantive os exemplos de paralelismo, carga temporária/MERGE, pivot, branching, recorte histórico, CSV manual e monitoramento.

Não incluí todas as versões com nomes diferentes: havia alternativas de um mesmo pipeline e DAG IDs repetidos. Também deixei fora um rascunho com erro de indentação, um teste de login, um utilitário de contagem de linhas e versões específicas de cliente que não acrescentavam uma técnica distinta a esta seleção. Não publiquei __pycache__, .env, dados exportados ou credenciais.

Os nove arquivos são adaptações dos códigos fornecidos. Os diagramas foram extraídos do código; a captura é uma evidência histórica separada e não comprova execução de todas as versões publicadas.
